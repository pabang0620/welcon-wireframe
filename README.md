# 웰콘 포지션매핑 와이어프레임

콘텐츠 해외진출 기업정보 구축 기획(1단계) 위탁사업의 회원가입 화면 프로토타입.

## 데모

https://pabang0620.github.io/welcon-wireframe/

## 구성

welcon.kocca.kr 실제 회원가입 화면을 클론한 정적 HTML 프로토타입이다. 서버와 저장 기능은 없고(선택 결과는 새로고침하면 사라진다), CSS·폰트·아이콘 등 정적 자산은 welcon.kocca.kr에서 실시간으로 불러온다. 오프라인에서는 정상 동작하지 않는다.

| 파일 | 내용 |
|---|---|
| `signup-step3-member-info.html` | 회원정보입력 화면에 "공통모듈" 선택 위저드를 이식한 본체 |
| `position-experience.html` | 공통모듈 위저드만 남긴 포지션 체험 페이지 (위저드 코드는 STEP3와 같은 복사본) |
| `signup-step4-company-info.html`, `index.html` | 기업정보입력 화면 (공통모듈 없음, 두 파일은 같은 내용) |
| `genre.html` | 콘텐츠 등록의 장르·상세장르 선택 화면 클론 |

## 공통모듈 위저드

모달 4단계로 진행한다: 활동 장르, 내가 하는 일, 희망 파트너, 완료.

- 장르 9개와 직접 입력하는 "기타"(1개만, 타일에서 엔터로 확정) 중에서 활동 장르를 고른다
- 항목은 공통모듈 단계(기획, 투자, 제작, 제작지원·기술, 유통·배급, 플랫폼·서비스, 중개·에이전트, 마케팅·홍보, 제조·상품화, 기관·협회)로 묶여 있으며 필터와 검색을 쓸 수 있다
- 내가 하는 일은 주포지션 1개와 보조포지션 복수, 희망 파트너는 복수 선택한다
- 완료 화면과 메인 폼에 장르별 포지션 분포 그래프가 나오고, 그래프에 마우스를 올리면 위 요약의 해당 항목이 강조된다

위저드는 `signup-step3-member-info.html`과 `position-experience.html`에 같은 코드로 들어 있으므로 수정할 때 두 파일에 함께 반영한다.

> 검토용 프로토타입이다. 화면에 표기된 분류 체계는 확정본이 아니다.
