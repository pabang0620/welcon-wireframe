# 웰콘 포지션매핑 와이어프레임

콘텐츠 해외진출 기업정보 구축 기획(1단계) 위탁사업의 회원가입 화면 프로토타입.

## 데모

https://pabang0620.github.io/welcon-wireframe/

## 구성

welcon.kocca.kr 실제 회원가입 STEP4(기업정보입력) 화면을 클론한 프로토타입이다. 기업정보 입력 폼 위에 "공통모듈" 선택 위저드를 새로 이식했다.

- 공통모듈 선택 위저드는 카테고리 탭(기획, 투자, 제작, 제작지원·기술, 유통·배급, 플랫폼·서비스, 중개·에이전트, 마케팅·홍보, 제조·상품화, 기관·협회, 기타)과 항목 사이드바로 구성된다
- 주포지션 1개와 보조포지션 복수를 선택할 수 있으며, 항목 이름으로 검색도 가능하다
- 그 아래 장르 섹션은 체크 시 세부 카테고리(예: 게임 → 게임투자/제작/배급 등)가 펼쳐진다

`index.html` 단일 파일이지만 CSS·폰트·아이콘 등 정적 자산은 welcon.kocca.kr에서 실시간으로 불러온다 (로컬 assets 폴더 없음). 오프라인에서는 정상 동작하지 않는다.

> 검토용 프로토타입이다. 화면에 표기된 분류 체계는 확정본이 아니다.
