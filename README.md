# 웰콘 포지션매핑 와이어프레임

콘텐츠 해외진출 기업정보 구축 기획(1단계) 위탁사업의 회원가입 화면 프로토타입.

## 데모

https://pabang0620.github.io/welcon-wireframe/

## 구성

4단계 위저드 - 활동 장르 선택 → 우리 회사(회사카테고리) → 찾는 파트너(희망비즈니스) → 완료

- 회사카테고리는 주포지션 1개와 보조포지션 복수로 구성한다
- 희망비즈니스는 회사카테고리와 같은 목록을 공유하며, 이미 고른 항목은 음영으로 표시된다
- 장르·공통모듈 필터와 항목 검색을 제공한다

외부 의존성이 없는 단일 HTML 파일이며, `index.html`을 브라우저로 열면 그대로 동작한다.

> 검토용 프로토타입이다. 화면에 표기된 분류 체계는 확정본이 아니다.
